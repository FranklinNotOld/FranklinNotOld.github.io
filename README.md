# Yongkang Li — personal homepage

Plain static files for GitHub Pages; no build step except the blog.

- `index.html` — home page (bio, projects, publications, blog preview, experience, contact)
- `projects/workzone.html` — Work Zone Risk Prediction project page (`assets/project.css` styles project pages)
- `blog.html`, `blog/` — generated by `tools/build_blog.py`; don't edit by hand
- `content/notes-en/` — English versions of the Chinese study notes; the blog shows English by default and switches to 中文
- `assets/site.css`, `assets/site.js` — shared look and the left-side menu. Add a menu entry by adding one line to `NAV` in `site.js`.
- `assets/post.js`, `assets/blog.css` — render and style blog posts (marked + KaTeX + highlight.js from cdnjs)

## Blog

Posts come from the Markdown notes in `Deep Learning from Zero to Kang`. To add one, put the `.md` file (and its `pic/` folder) there, add a line to `SERIES` or `NOTES` in `tools/build_blog.py`, then run from this folder:

```bash
python tools/build_blog.py "../Deep Learning from Zero to Kang"
```

## CV

`assets/cv/Yongkang_Li_CV.pdf` is built from `../cv/cv.tex` (pdflatex, TeX Live). After editing it:

```bash
pdflatex cv.tex && cp cv.pdf ../site/assets/cv/Yongkang_Li_CV.pdf
```

Before overwriting, copy the current site PDF to `../cv/archive/` with a date and version suffix (e.g. `Yongkang_Li_CV_2026-10-25_v1.pdf`).

The public version deliberately leaves out the phone number and the undergraduate institution.

## Preview

```bash
python -m http.server 8766
```

Then open http://localhost:8766.

## Publish

`../deploy` is a clone of the `FranklinNotOld.github.io` repository, and this folder is its whole content. Every push to `main` runs `.github/workflows/pages.yml`, which deploys the repository root to GitHub Pages (about a minute). To publish, mirror this folder into the clone and push:

```bash
cd ../deploy && git rm -rq . && cp -r ../site/. . && git add -A && git commit -m "Update site" && git push
```

The 2024 site is kept in `../archive/old-site_2026-10-25/` and in the repository history.
